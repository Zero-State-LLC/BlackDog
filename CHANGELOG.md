### Added

- T04 follow-up (N6): `nonlinear-suite-v1` renders eight float32 stimuli (impulse, analytic Farina sweep with a 10 ms fade and a documented passband, 997 Hz at peak −1 and −20 dBFS, SMPTE 60 Hz + 7 kHz at 4:1, two RMS noise levels with a silent first sample, and a DC step then silence), each at the 144000-frame floor. The pass gate is the signed per-sample check. THD+N, IMD and the Farina inverse filter are diagnostics and are left out of the reproducible digest. Every signal render pins `-ftz 0` and refuses `-fm`, so a diagnostic compile and a reward compile of the same source share one digest. The suite is not in `REWARD_PROFILES`. TaskSpec `effect` is required (`linear`, `time_invariant`, `nonlinear`, `time_variant`); only the first two are rewardable, and a missing or misspelled value is rejected. `profile_digest` stays version 2, so the frozen impulse digests are unchanged when `-ftz 0` is pinned. `require_task_rewardable` is called by `dataset_reward_row` and `rl_batch` (D5). `nonlinear-suite-fallback-v1` is the four-stimulus fallback. x86 goldens cover a five-program DSP bank. `tanh_sin_shaper` is a real `tanh` then `sin`; that program's hashes were reviewed and replaced, and the other four programs were not re-rendered. A golden sample hash is the raw little-endian binary32 bytes, so distinct NaN payloads do not match. `scripts/signal_cross_arch.py` runs without installing the package and compares those hashes; CI is x86 only, so the ARM side stays pending on the DGX Spark. A mismatch is `infra_fault` and does not widen the tolerance. The denormal-decay bank program rendered in 54 ms of worker time.

- T03b follow-up: a diagnostic line that is exactly `ERROR : stack overflow in eval`, Emscripten's `Aborted(stack overflow)` line, and a line that is exactly `Maximum call stack size exceeded`, stay exit 126 `internal`. libfaust-wasm sometimes returns that evaluator crash instead of dying with `SIGSEGV`. Any other `ERROR :` or `WARNING` stays a source failure (exit 1), including when Faust echoes `TypeError`, `stack overflow`, or a slider label. JS exceptions match only at the start of a line (`TypeError:`, `RangeError:`, `ReferenceError:`, `SyntaxError:`, `InternalError:` followed by a space), case-sensitive.

- T03b follow-up: diagnostic lines split on `\n` only. U+2028, U+2029, NEL, VT, FF, and the file separators cannot open a fake JS exception. An absent prefix, fallback, or reported Faust directory is refused unless `realpath` of its parent is root-owned and not group- or world-writable, so the caller cannot create it before exec. A symlink such as `/usr/share` is checked at its target. `scripts/install-faust-2.88.0.sh` creates `/usr/share/faust`, `/usr/local/share/faust`, and `<prefix>/bin/architecture` root-owned mode `0755`. `faust --libdir`, `--dspdir`, `--includedir`, `--archdir` and `--pathslist` fail closed unless each exits 0 and `--pathslist` prints `FAUST dsp library paths:`. The script checks the release tarball sha256 `e4e175cf236924b5b7d4784cbb8c50cc01e211159e169655dd9e6d8f92b871d9` before it extracts.

- A Faust stack-overflow line breaks on `\n` only, so NEL and U+2028 cannot open a match. `runtime_stack_overflow` is set only for a RangeError whose message is exactly `Maximum call stack size exceeded`.

- T03b follow-up: the native sandbox also masks `<binary>/../share/faust`, `<binary>/../lib/faust`, and every directory `faust --libdir`, `--dspdir`, `--includedir`, `--archdir` and `--pathslist` print, except the hashed private copy. A library planted beside a copied `faust` binary cannot be imported. CI installs Faust 2.88.0 so that check runs.

- T03b follow-up: creating the share lock directory happens while the in-process lock's release is armed, so a failed `mkdir` cannot stick the lock. The native sandbox masks `/usr/share/faust` and `/usr/local/share/faust` when they exist. Faust cannot fall back to them after `-I`.

- T03b follow-up: the in-process share lock and the file lock share one 30-second deadline. A directory at the lock path raises `SandboxError`. Native compiles hash a private copy of the share and pass that copy as `-I`.

- T03b follow-up: waiting for the faustlibraries share lock is bounded. A timeout raises `SandboxError` instead of blocking a cold publish. The lock file is opened with `O_NOFOLLOW` and a symlink is refused. After a tamper refusal, delete `share-<commit>` and re-stage; the harness does not delete that tree itself.

A unit is admitted only when `(repo, commit, path, function, blob_sha)` is a cleared T05 unit, and the ingested bytes must hash to that blob id before normalization. T06 does not execute `rights_cleared` or `rights_rejected`. Near-duplicate families intersect rights, and a family that mixes licenses is quarantined. Rejected and `needs_human` blobs are fetched for near-duplicate clustering and are never emitted; a cleared near-copy or a verbatim excerpt of one is `needs-human`. Four upstream originals copied by syfala on 2024-02-13 stay cleared only when every non-cleared family member is that entry's recorded copy. A cleared file that vendors a shorter rejected blob, plus its own padding, is `needs-human`. Reverse containment quarantines a cleared file when at least half of a rejected text's shingles sit in it, including after one edited literal per statement or when those statements are interleaved with the cleared file's own code. `TOKEN_FLOOR` is the single length constant for the Jaccard minimum and the verbatim run (currently 40). - Quarantine replay refuses a second resolve for one row and an `outcome` that does not match the attribution (`parse_error` for source, `drop` for harness or infrastructure). Source triage requires evidence. `triaged_at` must be a timezone-aware ISO-8601 timestamp, not in the future, and not earlier than the quarantine hold. A passed RL reward must be exactly 1.0. Compiler exits 137, 139 and -9 are queued crashes. A worker signal, a JS `runtime_stack_overflow` flag, and a `wasm_trap` kind are structured receipt fields. - Reward grader production path (spec §23): `commit_signal_check` and reward-graded `run_signal` grade through a persistent quarantine log and the A7 tracker. Compiler exits 124, 125 and 126, and worker or harness crashes, are held or refused. `REWARD_PROFILES` is the only allowlist literal and `profile_digest` is the only profile digest. Receipt signing stays deferred (D3). `resolve` requires a triage attribution, who triaged the row, and when. `source` is `parse_error`. `harness` and `infrastructure` are dropped and not scored. Unresolved rows stay quarantined. A reward-graded `run_signal_suite` takes the ledger, and `commit_signal_check` grades compiler exits 124, 125 and 126 and render crashes. The A7 alarm is above 1% over a full 500-sample window, or above 2× the baseline. `rates.json` is single-process.

- Reward grader (N4, N5, spec §23): `grade_receipt` mints a `RewardableSignalReceipt` only for an allowlisted reward profile (`impulse-44100-v1`, `impulse-48000-v1`), recomputes both digests, and rejects diagnostic receipts, tampered digests, unknown profiles, unknown schema versions and extra fields as `Ungraded`. ### Fixed

- Grader: a bare exit-1 `ERROR : stack overflow` line stays ungraded and quarantined unless a sealed Faust 2.88.0 `faust-cli` cpp receipt exits exactly 1 with that same line. A `triage="source"` string, and any recorded triage decision, cannot turn an unattributed 124, 125, 126 or crash into 0.0 while A2-T is unimplemented. A harness or infrastructure `TriageDecision` drops a remote-import or source-size score. A compiler receipt with `termination_signal` set stays ungraded. Native mint accepts `exit_code` only when `type(exit_code) is int` and the value is 1, and it checks every `-lang` in the command. A command that omits `-lang` is refused. `apply_signal` refuses a receipt minted for an unrewardable task, including a tuple `classes` entry. `UngradedRateTracker.load_state` restores `baseline`. The unused `reward_profile_allowlist` helper and the dead `_source_tag` stage argument are gone.

- Faust directory queries read stdout as bytes and decode it with `os.fsdecode` (`surrogateescape`). A `--pathslist` line that is not decodable, including a nonexistent path that carries a byte such as `0xec`, raises `SandboxError` instead of `UnicodeDecodeError`. A well-formed absolute path that is not on disk is still returned so the mount can cover it.
